# Changelog

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
and this project adheres to [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-06-22

### Added
- Curated directory of 9 AI agent skill/extension ecosystems across 3 categories
  (skill & tool protocols, platform skill systems, and skill/agent marketplaces),
  with open-source/license metadata.
- `skill-dir` CLI: list (filters: category/open-source/proprietary), search,
  categories, stats, export (json/csv), generate.
- Auto-generated README, registry-integrity tests, and CI (incl. README-in-sync check).
